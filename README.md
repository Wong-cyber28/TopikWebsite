# 🎓 AgentTOPIK: AI-Powered TOPIK II Essay Evaluator

AgentTOPIK is a full-stack, cloud-deployed intelligent grading and feedback platform designed specifically for the TOPIK II Question 54 (Academic Essay). Powered by a dual-agent LLM architecture, it provides automated, rubric-aligned evaluations, personalized vocabulary upgrades, and data-driven progress tracking.

🌐 **Live Demo:** [AgentTopik Website](https://agenttopik.streamlit.app)

---

## ✨ Key Features

- **Dual-Agent Pipeline:** Separates linguistic correction from logical evaluation to mimic a rigorous academic review process.
  - *Agent 1 (The Grammarian):* Focuses on spelling, spacing, and formal plain-form (`한다/ㄴ다`) syntax corrections.
  - *Agent 2 (The Professor):* Evaluates task fulfillment based on official TOPIK rubrics and injects a "Mid-Level Cap" to prevent score inflation for generic structures.
- **Dynamic Content & Snippet Modes:** Automatically detects essay length; provides quick linguistic validation for snippets (<400 chars) and a full 50-point breakdown for complete essays.
- **Full Internationalization (i18n):** Seamlessly toggles the entire user interface and AI analytical reports between **English, 中文, and 한국어** based on user preference.
- **Persistent Progress Dashboard:** Integrates a relational database to track analytical score curves over time and builds a personalized "Advanced Vocabulary Bank" for active learning.

---

## 🛠️ Tech Stack

- **Frontend & UI:** Streamlit (Dynamic layout, custom columnar positioning, and seamless multi-language state management)
- **AI Orchestration:** Google GenAI SDK (Leveraging advanced system instructions and strict JSON schema outputs)
- **Database / Storage:** SQLite3 (Server-side structured storage for multi-dimensional grading logs and historical vocab items)
- **Data Analytics:** Pandas (On-the-fly vector transformation for chronological performance visualization)

🚀 Getting Started (Local Development)
Prerequisites
Python 3.9+
A Google Gemini API Key

Installation
Clone the repository:

Bash
git clone [https://github.com/Wong-cyber28/TopikWebsite.git](https://github.com/Wong-cyber28/TopikWebsite.git)
cd TopikWebsite

Install dependencies registered in the procurement manifest:

Bash
pip install -r requirements.txt

Configure your local environment variables by creating a .env file:

Plaintext
GEMINI_API_KEY="your_actual_api_key_here"

Launch the application:

Bash
streamlit run app.py
